# Spec-048 文献地图 tab 化与刷新图标：人工验收可复现步骤（2026-11-13）

> 适用范围：把「新建地图」从左侧栏大表单改为页面级 `地图` / `新建地图` 两个 tab；把「刷新状态」从顶部文字按钮移到画布卡片头部工具区、改为**无可见文字的转圈图标按钮**。交互与状态刷新语义不变（纯前端 DOM / 样式重组，无后端改动）。
> 服务地址：`http://127.0.0.1:8000/`；启动命令 `./deploy/start.sh -d`，端口占用时 `PORT=8300 ./deploy/start.sh -d`（地址相应改为 `http://127.0.0.1:8300/`）。
> 产物性质：纯文档，供验收人在真实浏览器按步复现；与 spec「产品使用步骤」段「人工验收案例（可执行，2026-11-13）」小节互为索引。

## 0. 前置（启动 + 硬刷新）

1. 启动服务：在项目根目录执行 `./deploy/start.sh -d`；若 8000 被占用，改执行 `PORT=8300 ./deploy/start.sh -d`，并把下文所有地址替换为 `http://127.0.0.1:8300/`。
2. 健康检查：浏览器打开 `http://127.0.0.1:8000/api/health`，显示 `{"status":"ok", ...}` 即通过；`connection refused` 回到第 1 步重启后重试。
3. **硬刷新**（macOS `Cmd+Shift+R`）：本轮把静态资源升到 `literature-maps.js?v=48` 与 `literature-maps.css?v=36`，不刷新会命中旧缓存、看到旧界面。
4. 核对版本生效：右键「查看网页源代码」，确认首个 live 链接为 `/assets/literature-maps.js?v=48` 与 `/assets/literature-maps.css?v=36`；`frontend/index.html` 末尾注释区可见 `v=47` / `v=34` 的纯属性 marker，**仅注释、不加载**，不是生效资源。
5. 核对无误后，桌面与 ≤760px 窄屏各走一遍 §1 / §2。

## 1. 桌面路径（≥1024px，步骤 1–4）

| 步 | 操作（点什么控件） | 点击后提示 / 看到什么结果 | 等待条件 | 下一步 |
|---|---|---|---|---|
| 1 | 左侧导航点「文献地图」 | 页面顶部（`.literature-map-header` 下）出现 `地图` / `新建地图` 两个 tab；`地图` 高亮（`aria-selected="true"`），下方为「列表 + 画布 + 详情」三栏，`新建地图` 面板 `hidden` 不可见 | 三栏工作区渲染完成、无加载骨架 | 进入步 2 |
| 2 | 点「新建地图」tab | 整块切到「新建主题地图」表单 tabpanel（独立面板，不再挤在左栏卡片）；`新建地图` 高亮、`地图` 取消高亮；只切 `hidden` / `aria-selected` / `tabIndex`，不重建表单 | 表单字段（主题 / 名称 / 年份 / 首批数量 / 来源 / 会议 / 项目）可编辑 | 填「主题」→ 点回「地图」→ 再点回「新建地图」，确认已填主题仍在；进入步 3 |
| 3 | 表单填完点「开始建图」 | 自动切回「地图」tab；状态栏显示「生成中…」，列表出现新地图条目；`#literature-map-create-panel` 为 `hidden` | 等「生成中…」稳定、列表可见新地图（不必等全部节点生成完） | 进入步 4 |
| 4 | 在画布卡片头部工具区找到**转圈图标按钮**（无可见文字，紧邻缩小 / 放大 / 适应等工具） | 悬停 tooltip「刷新状态」（`title` + `aria-label`）；点击后图标加 `is-spinning` 开始旋转；按钮无文字残留 | 等旋转停止（`is-spinning` 移除 = 请求结束）、列表 / 作业状态更新；按钮可重复点击 | 桌面路径完成 |

## 2. ≤760px 窄屏路径（步骤 1–4）

| 步 | 操作（点什么控件） | 点击后提示 / 看到什么结果 | 等待条件 | 下一步 |
|---|---|---|---|---|
| 1 | 浏览器宽度设 ≤760px（DevTools 设备模式），左侧导航点「文献地图」 | 两个 tab 横向可见可点；`地图` 默认高亮，三栏按窄屏布局折叠呈现 | tab 可点击、无横向溢出遮挡 | 进入步 2 |
| 2 | 点「新建地图」tab | **整块**切到表单面板；**不弹出列表抽屉**（不再触发 `openMobilePanel('list', ...)`）；表单可上下滚动，字段可编辑 | 表单滚动到底可见「取消 / 开始建图」 | 填「主题」→ 来回切 tab 确认值保留；进入步 3 |
| 3 | 点「开始建图」 | 回到「地图」tab，状态栏「生成中…」，列表出现新地图 | 等生成中状态稳定 | 进入步 4 |
| 4 | 画布头部点转圈图标按钮 | 图标按钮可见、触摸目标 ≥44px；点击后旋转并刷新；无可见文字残留 | 等旋转停止、状态更新 | 窄屏路径完成 |

## 3. 键盘切 tab（补充验收）

| 按键 | 操作 | 预期结果 |
|---|---|---|
| `Tab` | 把焦点移入 tablist | 焦点落在当前选中 tab（`tabIndex=0`），未选中 tab `tabIndex=-1` |
| `→` / `←` | 在 tab 上按方向键 | `地图` ⇄ `新建地图` 切换，`aria-selected` 与 `tabIndex` 同步，panel 随之显隐 |
| `Home` / `End` | 在 tab 上按 Home / End | 跳到首个 / 末个 tab，同步 `aria-selected` / `tabIndex` |
| `←` 切走再切回 | 键盘切到「新建地图」填值、切走再切回 | 表单值不丢失（面板不重建） |

## 4. 自然语言入口

本范围不新增也不修改自然语言交互（无对话框 / 指令输入等 NL 入口），产品主路径为 tab 点击与图标按钮点击；本项标记「不适用（非本范围改动）」，不做形式化验证，不以内部 API 调用替代主路径点击。

## 5. 失败恢复

| 现象 | 恢复动作 |
|---|---|
| tab 不切换 | ① 硬刷新 `Cmd+Shift+R`；② 查源代码 live 链接是否 `literature-maps.js?v=48`；③ DevTools 核对该元素 `role="tab"` / `aria-controls` / `data-map-tab` 是否齐全；仍不切换则截图记录，回到 `docs/sdd/reviews/048-*.md` 的 DOM 契约核对项，暂停验收并上报 |
| 表单值丢失 | 核对是否走了「重建面板」路径（应只切 `hidden` / `aria-selected` / `tabIndex`）；对照边界 2 与 C2 记录复现步骤，暂停验收并上报，不以重新填写硬凑通过 |
| 图标不旋转 | ① 确认点的是画布头部图标按钮而非其它工具；② 查 `is-spinning` class 是否加上、是否处于禁用态或 `prefers-reduced-motion`（此二者按设计不做持续动画，属预期）；③ 服务不可达会提前结束旋转，见下行 |
| 旧缓存命中 | 硬刷新；查源代码首个 live 链接为 `literature-maps.js?v=48` / `literature-maps.css?v=36`；若仍见 `v=47` / `v=34` 清站点缓存后重刷；`index.html` 末尾注释区的旧版本纯属性 marker 仅注释、不加载，勿误判为生效资源 |
| 服务不可达 | `curl http://127.0.0.1:8000/api/health` 应返回 `{"status":"ok"...}`；`connection refused` 用 `./deploy/start.sh -d` 启动（端口占用改 `PORT=8300 ./deploy/start.sh -d` 并替换地址），仍失败则记录阻塞、不宣称验收通过 |
