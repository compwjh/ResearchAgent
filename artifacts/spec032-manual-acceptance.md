## 核心成功路径

### 1. 创建研究 Intake

- **操作**：点击新建会话（或首页聊天输入框），在“给 Ollama 发消息”输入框粘贴：

  `帮我做一个深度研究，主题是 USENIX Security 2024 中的身份认证、访问控制与权限保护。目标是从 USENIX Security 2024 官方目录中选择至少 5 篇相关论文，比较它们要解决的安全问题、研究方法、攻击模型和主要结论，时间范围：2024-2024。来源只使用 USENIX Security 官方目录。如果官方页面没有提供关键词，请明确标记为官方未提供，不要自行生成。`

- **点击后提示**：助手消息应出现“研究 Intake 已完成”或同义状态，并出现计划卡片，状态为“待审批/等待批准”。
- **等待**：等待 SSE 卡片从“处理中”变为 Intake/计划卡片；不要重复点击发送。
- **等待中显示**：应能看到“正在解析研究主题、目标和时间范围”之类的处理步骤。
- **下一步**：如果页面显示“请补充：时间范围”，在同一会话输入 `时间范围：2024-2024。` 后发送；看到 `missing=[]`/计划卡片再继续。
- **失败恢复**：若显示“事件流中断”，先点击页面的“重连/刷新任务”按钮一次；仍失败则记录 conversation ID，不要新建多个任务。

### 2. 审批研究计划

- **操作**：在“计划审批”卡片核对目标、范围、来源为 USENIX Security 官方目录和 2024–2024，点击“批准计划”。
- **点击后提示**：应显示“计划已批准，研究执行已获批准，正在排队”或同义提示；审批按钮应变为已批准/不可重复提交。
- **等待**：等待处理卡片依次出现“目录检索”“论文评估”“覆盖检查”“报告生成”。
- **等待中显示**：页面应展示当前阶段、完成数量或心跳；不能只显示静态 `Queued · 0%`。
- **下一步**：阶段进入“报告生成/已完成”后，点击“查看报告”或 Artifact 下载链接。
- **失败恢复**：若显示“已有进行中的研究”，选择“取消后新建”只应在确认放弃旧任务后使用；若任务是 `waiting_login`/`failed`，应点击对应的登录、继续或重试动作，不要重复批准同一版本。

### 3. 检查论文选集和报告

- **操作**：打开“论文选集/候选评估”和最终报告。
- **成功提示**：至少显示 5 篇 USENIX Security 论文，每篇包含标题、摘要、官方关键词（缺失时显示“官方未提供”）、安全问题、研究方法和来源链接。
- **等待**：若候选评估尚未完成，等待 Worker 卡片变为“已完成”；不要在此时刷新或重新发起研究。
- **下一步**：下载或打开 Markdown Artifact，确认报告章节包含方法与安全问题的横向比较，并能通过引用回到候选论文。
- **失败恢复**：若只有内部 `catalog:<id>` 或“该论文提供元数据”占位文本，判定失败，记录 Artifact ID 和页面截图，不接受为成功案例。
