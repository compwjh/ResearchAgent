## 统一执行规则

- Task 开发阶段只运行与本 Task 相关的定向测试；只有 Task05 执行一次全量回归。
- 下游角色只读取 Spec024、当前 Task、其中列出的代码路径及上一角色固定报告，不扫描整个项目。
- 线上子 Agent 正常运行时等待其主动返回，不频繁读取日志；仅在超时、报错或明确阻塞时诊断。
- 推理草稿与 ProcessingStep 是不同数据：前者是模型返回的可见 reasoning 流，后者是产品工作流阶段。
- 任何范围变化，尤其是 RAG、模型切换、上下文压缩或 Ollama 部署改动，必须停止并回到 Spec。
- 实现、定向测试和评审证据统一写入 docs/sdd/plans/024/artifacts/task-NN/。
