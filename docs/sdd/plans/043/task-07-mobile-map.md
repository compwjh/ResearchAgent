## 实施步骤与文件边界

1. 小屏切换单图谱主画面，地图列表/筛选与论文详情使用可关闭抽屉，保留现有主导航逻辑，不重复侧栏。
2. 区分单指平移/节点点击与双指缩放；移动端点选不依赖hover，避免图拖动劫持页面抽屉滚动。
3. 支持地图创建、搜索定位、关系开关、节点详情、候选预览确认及状态提示；与桌面使用同一后端数据/布局，不能另存一套图。
4. 桌面拖动布局、右侧详情和鼠标操作回归；抽屉打开时焦点/返回/关闭可用，长标题和缺失摘要不撑破布局。
5. 用真实浏览器测试窄屏触控模拟，优先补真实手机可用证据；模拟与真机明确区分，不虚报真机验收。

允许范围：仅frontend地图交互/响应式/契约测试；若发现后端独立缺陷另交backend-dev，不因CSS触发全后端回归。
