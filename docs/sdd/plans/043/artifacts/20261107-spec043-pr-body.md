## 全量回归修复说明（用户要求的 PR 前置）

首次全量回归有 2 个失败（`tests/paper_discovery/` 的临时目录清理断言），用未含本 PR 改动的 HEAD 快照复跑同样失败，确认为既有缺陷。根因：IDE 注入的**仓库外** `sitecustomize` shim 包装了 `shutil.rmtree`（未转发 `avoids_symlink_attacks`），并替换了 `os.unlink` / `os.rmdir` 函数对象，导致 `paper_import.py` 的删除能力检测误判、跳过自建临时根清理。

修法：新增 `_rmtree_is_symlink_attack_resistant()`——能力标记存在时用标记，缺失时按平台 `dir_fd` 能力**名称**判定；保留 `lstat` / `S_ISDIR` / `is_symlink` / dev-ino token 校验与 fail-closed 语义，不改下载/入库/索引/补偿逻辑。新增 4 条非恒真回归用例，并同步 `upload-closure-matrix.json` 的 sha256 与 `inventory_digest`（该清单是活的安全锁，历史已有刷新先例；纯 JSON 配置同步由主会话代行，留痕于台账、本 PR 正文与 commit message）。
