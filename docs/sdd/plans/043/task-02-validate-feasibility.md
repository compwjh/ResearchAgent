## 实施步骤与文件边界

1. 核对现有S2 search_bulk/batch/graph_edges请求及身份字段，使用现有共享限流客户端取得受控小样本，验证引用者→被引用者方向；不读key值、不抓HTML。
2. 选择并保存可复现主题/可选年份/来源/参数，以及一组真实引用论文ID和一组真实相似对，记录请求状态/数量/缺失/时间，不将固定合成图当真实数据。
3. 核对目录关联：S2 ID与catalog ID分开、DOI/arXiv确定匹配、标题近似不自动合并；列出窄适配接口缺口。
4. 复用现有embedding对真实标题/摘要计算相似，记录模型版本/基准阈值0.75；若暂不可用记录blocked并单测降级，不能降低阈值冒充成功。
5. 前端在隔离测试样例评估SVG200节点（引用和稀疏相似）、缩放/拖动/布局调度；性能样例必须标synthetic，不计入真实API成功。
6. 给出Go/No-Go和具体复用契约、预算与重试上限建议。选用现有客户端有限退避，不另建provider。缺摘要/关键词不构成No-Go；缺核心数据/API权限才阻塞。
7. 确认服务/向量/账号能力不误判：网络受限先按授权可达性验证，不把沙箱失败写成provider停止。

允许范围：后端只读接口核对及必要能力命名测试/固定脱敏样本；前端只做隔离性能样例和契约测试，不提前发布地图入口，不做生产迁移。
