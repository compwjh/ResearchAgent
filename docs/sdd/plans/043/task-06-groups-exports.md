## 实施步骤与文件边界

1. 实现分组创建/重命名/删除与节点归属的版本化更新；删除组节点回到未分组，不删除论文，颜色不表示学术立场。
2. 图布局/筛选/分组变更按revision合并，刷新保护人工设置；不自动聚类，不用距离创造引用。
3. JSON导出包含schema_version、map配置、稳定身份、元数据provenance、节点布局与分组、边方向及similarity依据；明确只导出授权地图，不含凭据/内部prompt/隐藏推理。
4. PNG由当前SVG图谱快照生成，包含图例/标题与合理清晰度，不含详情弹窗/工具条；纯前端导出不增加后台PDF渲染器。
5. 缺图谱字体/图太密时提供适应画布再导出提示；失败明确，不把零字节文件当成功。JSON导入功能不在本期。
6. 定向验证与浏览器导出后实际打开PNG核查，解析JSON核对节点/边数与依据。

允许范围：分组/视图持久化及地图导出接口、SVG导出控件，不修改个人KB导出或新增图数据库。
