## 2. 路径 A：复核 fresh 地图、摘要队列、标签、节点半径与鼠标锚点

### 步骤 A0：打开产品入口

**点击/输入**

1. 在浏览器打开 `http://127.0.0.1:8000/#literature-maps-view`。
2. 如果当前仍在其他工作区，点击左侧主导航 **文献地图**。

**点击后提示**

页面标题区域应显示“文献地图 / LITERATURE MAPS”，并出现“刷新状态”“新建地图”和“我的地图”。

**等待**

等待“我的地图”出现地图卡片；以卡片出现为条件，不以固定秒数判断成功。列表短暂为空或处于加载态时，不要新建第二张 Task09 地图。

**下一步**

找到准确名称 `Task09 live graph attention networks 20261024-153416`，进入步骤 A1。

**失败恢复**

若入口打不开、服务错误或卡片始终没有出现，记录页面上的短错误提示并停止。不要重启服务、猜测地图深链接或创建替代地图；这些情况交由 QA/root 处理。

### 步骤 A1：打开 fresh 地图并等到摘要队列终态

**点击/输入**

点击地图卡片 `Task09 live graph attention networks 20261024-153416`。

**点击后提示**

地图标题和主题出现，图谱区域渲染 20 个节点、11 条关系。地图的真实状态仍为 `partial`，页面可能显示“地图部分完成；已保留可用节点并标注失败阶段。”这是当前 provider/来源覆盖的真实结果，不表示需要用户重新建图。

**等待**

等待节点可见且队列进入稳定终态。已验证的终态提示为：

`状态：已完成 / 完成 18/20 · 排队 0 · 运行 0 · 失败 0 · 跳过 2`

其中18篇有非空摘要，2篇因没有可用摘要而安全跳过；`skipped`不应被标题文本冒充为摘要。“运行中”可继续等待；若明确提示“用户已暂停”，需点击“继续队列”才会恢复，不要一直等。配置/鉴权导致的暂停则记录提示并停止，交QA/root处理，不盲目继续或反复刷新。

**下一步**

队列达到上述终态后，继续步骤 A2。可以把 `partial` 和 `18/20 + 2 skipped` 作为本次已验证结果记录下来；实时 provider 不保证每次来源都全绿。

**失败恢复**

如果队列仍为 `queued/running`，继续等待；如果出现新的 `failed` 或停在未知状态，记录计数和页面提示后停止。本固定回放不点击“重试失败单元”，不重复模型调用，也不要求用户修复 provider。

### 步骤 A2：核对标签三档

**点击/输入**

先找到作者/年份标签 `Petar Velickovic et al., 2017`，悬浮确认完整标题为 `Graph Attention Networks`，点击对应圆点打开详情，再在工具栏打开 **标签**，依次点击 **全部**、**选中及相邻**、**隐藏**。下方7个邻居标签的数量只适用于选中这篇论文；未选中节点时不应期待7个。

**点击后提示**

每次切换后，图中仍保留 20 个节点，真实标签数量应分别为：

- **全部**：20 个标签；例如 `Petar Velickovic et al., 2017`。
- **选中及相邻**：7 个标签。
- **隐藏**：0 个标签，但节点仍可选择，节点标题仍可由可访问名称取得。

标签模式切换不应改变节点位置、关系边或已保存视图。

**等待**

每次点击后等待节点和标签数量稳定，再切换下一档。不要把尚未稳定的动画/加载中 DOM 当成最终数量。

**下一步**

完成三档后，进入步骤 A3。保留当前标签模式即可，后续复核不依赖某一档。

**失败恢复**

若出现 `undefined`、`null`、空白标签、重复的 `et al.` 或节点数变化，保留截图和看到的模式，停止验收并交 QA/root。不要手工修改文字或刷新到另一张地图。v17/v18 的窄验已验证单次 `et al.`；旧候选中的重复文本只作为历史失败证据保留。

### 步骤 A3：查看节点半径与选中态

**点击/输入**

在图谱中选择 `Graph Attention Networks`。如果圆点重叠，先让目标节点获得键盘焦点，再按 `Enter`；这与鼠标点击是同一真实可访问入口。

**点击后提示**

右侧“论文详情”应显示该论文的真实标题、作者/年份、venue、引用数 `29148`、摘要及分析区域。选中节点的描边/选中态会变化，但节点圆半径不会因选中而改变。

已验证的引用半径规则为 `min(28, 8 + 2*ln(1+n))`。fresh 图的 20 个节点均有合法引用数；代表值为 `29148 → 28`、`2183 → 23.3778267`、`681 → 21.0500593`、`77 → 16.7134`。这表示引用越多节点越大，超过上限后保持最大半径 28。

**等待**

等待详情面板完成加载，确认节点仍在图中且位置没有因打开详情而重排。

**下一步**

保持详情打开，进入步骤 A4 测试缩放；随后在步骤 A5 查看摘要。

**失败恢复**

若目标节点无法获得焦点、标题/引用数与本页不符或打开详情导致节点消失，记录可见提示并停止。不要拖动节点修正布局，也不要通过新建地图替代目标节点。

### 步骤 A4：复核鼠标锚点、工具栏中心和页面滚动

**点击/输入**

1. 点击工具栏 **重置视图**。
2. 将鼠标放到画布的非中心留白处，滚轮一次。
3. 点击工具栏 **放大**，观察以画布中心为锚点的缩放；需要时用 **缩小**，最后再次点击 **重置视图**。
4. 打开详情后向页面下滚动，再在同一个非中心留白处滚轮一次。

**点击后提示**

非中心滚轮应围绕鼠标所在位置缩放，不应出现明显锚点漂移；工具栏“放大/缩小”以可视画布中心缩放；页面滚动位置不应被滚轮测试改写，详情仍可见。

**等待**

每次滚轮或按钮点击后等待画布变换稳定，再观察下一次操作。已验证的真实读数为：非中心滚轮从 `scale=1` 到 `scale=1.1`，锚点误差约 `(-0.090,-0.139)` viewBox 单位；工具栏中心缩放到 `scale=1.2`，中心误差约 `(-0.00002,-0.00001)`；详情和页面滚动复测仍通过。

**下一步**

点击 **重置视图**，回到稳定视图后进入步骤 A5。

**失败恢复**

若节点/标签明显漂移、页面滚动被意外改变或缩放越过边界，先点击 **重置视图**，保留看到的状态并停止。不要手工保存新的布局，也不要重复快速点击放大/缩小来掩盖问题。

### 步骤 A5：查看摘要，不重复生成

**点击/输入**

在当前节点详情的分析区域点击 **摘要**。

**点击后提示**

应能看到历史条目 `v1 · 摘要级 · 已完成` 和 `摘要级分析结果（仅基于摘要）`，正文非空。

**等待**

等待历史卡片和正文出现；已有完成结果出现后不需要再点任何生成按钮。

**下一步**

完成 fresh 地图复核后，回到主导航 **文献地图**，进入路径 B，查看已经入库并完成全文分析的固定节点。

**失败恢复**

若摘要暂时显示 `queued/running`，等待状态变化；若新版本失败，保留仍可读的旧 `v1`，记录页面提示并停止。不要点击“重新生成摘要（会调用模型）”，不要连续触发 provider 请求。
