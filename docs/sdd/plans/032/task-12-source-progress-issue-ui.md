## 定向验收

- 七来源按服务器返回动态渲染，不硬编码 USENIX/DBLP；未知字段和超长标题安全转义，加载中/空态/单源失败清晰。
- `waiting_login` 有打开登录与登录后继续，不误显示仅 failed 可用的 retry；上传正确/错论文分别给出可操作结果，索引中不可冒充已完成。
- 字段来源可展开；官网与聚合数据不混色/混名；来源失败留来源卡，不伪造论文待办。桌面与窄屏交互、键盘/焦点与 XSS 定向测试通过。
- 只跑前端契约、静态检查和真实浏览器定向 smoke；不跑后端全量回归。
