# 任务 08 — 执行测试、排序基准与安全回归

## 一句话目标

用离线可重复测试、冻结排序集、安全攻击样本和真实外部链路证明 spec-015 满足 A1–A14，并且不破坏已有聊天、知识库、观测和 Reranker 能力。

## 背景与前置条件

- 单元/集成测试默认使用冻结响应，不依赖公网波动；另设明确标记的真实网络验收。
- 测试基线取任务 02 记录值，并动态取 spec-013/014 最终验收通过数的最大值。
- 排序标签必须在首次查看最终 rerank 输出前冻结，后续只允许追加纠错记录，不允许静默改标签。

## 数据、配置与接口

- 建立 DBLP Venue/Search、OpenAlex、公开 PDF、ACM/IEEE 页面与错误响应 fixture。
- 建立不少于 12 条方向查询、每条至少 3 篇相关论文的冻结标注集。
- 指标至少输出 nDCG@10、Recall@10、查询级差异和灾难性退化清单。
- 覆盖所有新增 API 状态码、功能开关、任务状态迁移和敏感日志检查。

## 实施步骤与文件边界

1. 补会议配置、搜索校验、主会过滤、去重、会话过期和源降级单元测试。
2. 补 embedding/rerank 正常与异常响应测试，校验稳定排序、有限分数和降级标志。
3. 补 SSRF：IPv4/IPv6 loopback、私网、link-local、DNS 变化、跨协议与多跳重定向。
4. 补 PDF：HTML 伪装、错误 MIME、魔数异常、零页、损坏、加密、超限和断流。
5. 补命名：中英文、Unicode、保留字符、空标题、超长、同名不同 DOI 和目录逃逸。
6. 补导入状态机：单篇、批量、部分成功、等待登录、重试、并发重复和重启恢复。
7. 补旧知识库记录兼容：列表、检索、重建、删除和旧物理文件名。
8. 补前端 DOM 契约、Tab 切换、无 `innerHTML` 敏感渲染、按钮可见性和状态保持测试。
9. 运行冻结排序集，对比初排与最终排序；输出逐查询指标和总体结论。
10. 在受控环境执行真实 DBLP/OpenAlex/公开 PDF，以及用户参与的 ACM/IEEE 登录验收。
11. 扫描日志、trace、浏览器 profile 外路径和 Git 状态，确认无凭证或运行产物入库。
12. 运行全量测试、覆盖率、JS/HTML/CSS 静态检查和全仓冲突标记检查。

## 验收标准

- A1–A14 均有自动化或明确的人工/真实网络证据，不以口头说明代替。
- 全量测试数不低于任务 02 动态基线，项目覆盖率不低于既有 80% 门禁。
- 最终 nDCG@10 不低于初排，且无灾难性查询退化；结果和冻结时间可追溯。
- SSRF、伪 PDF、幂等、任务恢复、旧数据兼容和敏感日志测试全部通过。
- ACM、IEEE 登录验收由用户亲自认证；没有合法权限时真实记录阻塞而非伪造通过。
- 全仓冲突标记 0 命中，Git 中没有 profile、Cookie、PDF 运行产物或日志。

## 明确不做

- 不为通过指标删题、改标签、放宽安全断言或跳过失败测试。
- 不把实时公网用例混入默认离线测试导致 CI 随机失败。
- 不在本任务顺手重构无关代码；发现缺陷回到对应实现 task 修复并复验。
