# Spec050 讨论决策

用户已确认三轮设计决策，已汇总至[待确认 Spec050](../../specs/050-agent-safety-and-factuality.md)。需求与技术评审尚未执行。原始输入为用户提供的《ResearchAgent_Spec046.md》和《ResearchAgent_Security_Research.md》。

## 已确认

1. **两次验收，一个 Spec。** 第一次交付工具执行前防护、真实过程提示和攻防端到端案例。第二次交付 RAD、MARCH、PIGuard 接入和公开对照。全部确认的必做项完成后，Spec 才能收口。
2. **执行授权由服务端负责。** Agent 的联网、下载、写入、导入、外发动作，在真正执行前核对用户授权、工具权限、本次任务范围和具体目标。异步执行和重试同样校验。PIGuard 提供外部内容注入风险信号。未接入路径可以如实标记覆盖范围，该路径的高风险动作仍不得直接放行。
3. **事实核验按场景启用。** 普通问答维持现有流式正文。用户主动开启核验或研究报告流程明确启用核验时，先显示真实进度，核验后发布正文。区分未核验和部分核验。修订后新增或改写的事实须有证据才能标为已核验。
4. **27B 固定于实验协议。** 公开对照和指定验收固定同一 27B 版本，生产尊重用户选模和现有路由。PIGuard 承担注入检测，基础 4B 可用于事实核验。内存不足时，普通请求可明确降级，必须核验的敏感动作停止。README 区分实验主模型与产品支持模型。
5. **公开基准和产品验收分别取证。** 使用许可和版本可核实的数据，固定 27B、样本与配置，报告既有执行防护、官方 PIGuard 和本机复训 PIGuard 的对照。产品端到端单独核对工具实际效果、正常任务完成和真实界面。单列故障率、误拒率和延迟，冻结测试集前约定上线门槛。结果持平或退步如实记录，训练版保持非默认。
6. **检测器接入。** 第二次验收加载已复训的 PIGuard，与官方权重做公开同题对照。MARCH 可用基础 4B 验收。加载或推理不稳定时记录第二次验收阻塞，第一次照常推进。
7. **区分拒绝、授权与故障。** 违反硬规则直接拒绝。动作本身合法且缺少授权时，由用户确认具体动作、目标及范围，执行前服务端再次校验。辅助模型故障时停止必须核验的动作并提示重试。重试不得扩大原范围或重复已成功的副作用。
8. **首批产品验收案例。** 同一个自然语言论文检索下载任务，分别使用正常和含注入的隔离测试来源，核对正常任务完成、越权动作未执行及真实界面提示。API 回归另覆盖聊天原生工具调用、JSON 降级、研究 worker 和重试，以实际执行记录取证。
9. **事实核验不完整的发布行为。** 默认给出有证据的结论并明确证据缺口。未核验草稿可另行展开，须明确标注。正式报告缺少支撑关键结论的证据时，保留已有结果并标记部分完成。
10. **实验完成与默认上线分开裁决。** 产物可加载、对照可复现且结果如实披露，即可验收实验交付。先用独立验证集量测并冻结攻击成功率、误拒率、任务完成率和延迟门槛，再打开最终测试结果。未达上线门槛则继续使用已验证的模式。
11. **生产开关。** 工具授权、参数和目标校验持续执行。管理员可关闭辅助检测与核验，必须经过模型核验的动作在能力不可用时停止。弱化配置仅限隔离评测。新配置影响新任务，真正执行前仍检查权限撤销。
12. **任务内单动作确认。** 第一次交付即支持。仅对已经注册、硬规则允许且处在任务范围内的动作确认类型、目标和范围。确认只使用一次，目标变化和任务取消使其失效。超出任务范围的外部指令直接阻止。
13. **安全事件生命周期。** 事件独立保存，复用会话处理过程与研究时间线，以及既有所有者校验和留存规则。刷新可查脱敏事件，删除所属消息或任务时清理，无持久会话仅展示当次。
14. **未核验草稿。** 仅在主动启用核验的问答中可折叠查看，先过输出安全检查，明确标识。正式回答及引用只采用发布版本。研究报告保留证据充分部分和证据缺口。
15. **本地资源。** 离线训练、推理限并发及有界队列，实测有余量后才双模型常驻。记录排队、加载失败和内存峰值。超时普通问答明确降级，必须核验的动作停止且可安全重试。并发与超时由本机验证冻结。

## 已核实的前提

- 聊天原生工具调用与 JSON 降级共享 [ToolLoop](../../../../backend/app/skills/tool_executor.py)。深度研究使用独立的 [AgentRuntime 分发与校验](../../../../backend/app/research/application/agent_runtime.py)，即使复用默认工具表，仍需在自己的执行入口校验。
- [知识库问答](../../../../backend/app/api/routes_kb.py) 直接转发生成事件。启用核验的路径需要单独的正文发布边界。
- [RAD 数据卡](https://huggingface.co/datasets/BruceYg/RAD-Database) 当前区分快照中的检索库和待发布的完整评测文件。公开对照允许使用已获准的替代基准，须清楚标注。
