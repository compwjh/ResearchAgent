# Task 06：旧文档补建、韧性与性能

> 关联：[Spec 018](../../specs/018-knowledge-document-chunk-inspector.md) ｜ [任务索引](./README.md)
> 依赖：Task 04、05；被依赖：Task 07；当前状态：`待执行`

## 一句话目标

证明现有知识库文档无需重新 embedding 即可使用检查器，并补齐中断、损坏、大文档和窄屏场景。

## 当前证据

- 本机已有多份 v1/v2 PDF 数据，但不能把用户原文提交为测试 fixture。
- 清单是派生缓存，应能从原件与 Qdrant payload 重建。

## 前置门禁

- Task 04/05 各自评审通过。
- 真实用户数据测试只记录计数、hash 和状态，不落盘原文片段。

## 执行阶段

1. 对脱敏旧格式 fixture 执行迁移与首次清单补建。
2. 在受控本机数据上只读验证至少一份既有 v1/v2 PDF，证明 embedding 0 调用。
3. 模拟构建中断、服务重启、损坏清单、原件丢失、索引变化和并发打开。
4. 用接近上传上限的大文档验证页面懒加载、切片分段渲染和内存上限。
5. 以真实浏览器验证桌面双栏、窄屏切换、键盘和双向滚动。

## 子 Agent 分派

- backend-tester 负责后端韧性；frontend-tester 负责静态/交互契约；tester 汇总跨端。
- 测试不修改业务代码；发现缺陷分别回退 Task 04 或 05 由对应 dev 修复。

### 固定 Prompt

```text
你是 Spec018 的跨端 tester。先读 Spec018、Task06、Task04/05 执行结果和单端测试报告。验证旧 PDF 自动补建且 embedding 调用为 0；验证清单损坏/过期/中断/并发、原件丢失、partial 映射和大文档性能；真实浏览器验证桌面双栏、窄屏切换、键盘、重叠/跨页双向定位。用户文档只能只读，报告不得包含原文、绝对私人路径或敏感元数据。缺陷必须回派对应端，不得由 tester 修改代码。返回结论、证据、命令退出码、性能数据、缺陷清单、风险、后续动作与耗时。
```

## 主 Agent 校验

- 报告中没有用户文档内容。
- 每个缺陷都有对应端修复、复评和复测闭环。
- 性能结论包含样本规模、浏览器、峰值内存/渲染时间，不写“感觉流畅”。

## 测试与验收

- 旧文档、恢复、安全、性能与响应式全部达到 Spec 验收标准。

## 风险、停止与回滚

- 任何测试修改用户原件或向量立即停止；不得以 reset/clean 回滚。

## 产出物

- 单端报告、跨端韧性与性能报告、缺陷闭环证据。
