## 强制约束（实现必须遵守）

- **C1**：不允许修改 `backend/app/**` 下任何实现文件（含 docstring、注释、import 顺序）。`git diff --name-only` 必须只包含 `tests/**` 下的新增/修改文件。
- **C2**：新增测试文件必须全部含真实断言（`assert*`），禁止「只调用不断言」的空用例；实现侧若认为某分支难以断言，**必须记录到 spec 风险区**由架构师裁决，不得自造占位断言。
- **C3**：不允许引入任何新的第三方依赖（`requirements.txt` / `pyproject.toml` 零变更）。
- **C4**：不允许修改 `.coveragerc` / `pytest.ini` / `pyproject.toml` 中的 `--cov-fail-under` 或其他覆盖率相关配置项。
- **C5**：所有测试必须在**断网 + 无 Ollama 服务启动**的情况下能全部通过；任何需要真实网络/模型服务的用例必须用 `unittest.mock.patch` 或 `monkeypatch` 隔离。

## 风险定级：低

理由：
- 纯新增测试文件，不改业务代码，无回归面。
- 验收点全部可执行命令验证，无主观判断项。
- 唯一风险是「为凑数写无断言测试」——已通过 C2 + V3 双重约束消除。
