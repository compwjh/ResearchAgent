## 风险与建议

- **API 异常处理缺失**：代码中仅包含 `health.then` 回调逻辑，未见 `.catch` 或全局错误拦截。
  - 建议：若 `/api/health` 出现网络超时或服务不可用，前端需有降级提示或兜底视图，避免 UI 状态卡死。
- **空数据加载时序**：依赖 `health` 回调渲染，页面初次加载时需确保模型列表为空态直至接口返回完成。
  - 建议：确认在 `health` 请求期间无闪烁或非预期初始内容，防止体验问题。
