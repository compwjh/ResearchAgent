## 必审项

- [ ] 用户点击后能立即看到 USENIX 与 DBLP 两张来源卡片，而不是等待同步请求结束。
- [ ] 卡片能区分缓存命中、正在获取、完成、partial 和 failed，并且不暴露技术异常或凭证。
- [ ] 结果包含标题、摘要和官网关键词（若提供）；官网未提供时关键词为空而不是生成。
- [ ] 搜索范围只实现 USENIX Security；其他会议明确提示未支持，不静默走旧路径。
- [ ] 已同步年份不重复抓取；扩展年份范围只补缺失单元。
- [ ] 每页固定 10 篇，下一页不重新搜索或重排。
- [ ] 搜索只保存元数据；只有用户选择导入后才下载和验证 PDF。
- [ ] 单源失败仍可展示缓存/另一来源结果；无来源且无缓存才整体失败。
- [ ] 原有单篇/批量导入、登录和个人知识库行为保持可理解且不被新目录混淆。
- [ ] A1–A20 都能转成真实验收步骤，无“后续自行决定”的产品空白。
