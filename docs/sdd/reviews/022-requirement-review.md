# Spec 022 需求评审：Task02 桌面端项目记忆 MVP

## 评审范围

- 评审对象：`docs/sdd/specs/022-project-conversation-memory.md`、`docs/sdd/plans/022/README.md`、`docs/sdd/plans/022/task-02-desktop-memory-mvp.md`。
- 评审重点：Task02 是否能以桌面端最小纵向闭环交付项目记忆，而不把后续 Task 的治理、手机端和论文知识库能力提前纳入。
- 现状依据：当前首页聊天实际调用 `/api/agent/run`，现有聊天流式接口为 `/api/chat`；未发现已落地的 `memory`、`conversation` 或 `project` 领域实现。

## 结论

**通过（实施前需完成下列契约性修订；不改变 Spec022 范围）。**

目标、用户价值、桌面 MVP 范围、固定演示和未绑定项目负例均已足够明确，可以进入 Task02 实现。以下项目是进入实现前的必要澄清，不是新增功能；应写回 Task02 的“本任务冻结的契约/验收”或实现报告，避免前后端自行猜测。

## 已确认的需求边界

1. 首条有效消息才创建会话，不产生空会话。
2. 项目记忆只属于项目范围；未绑定会话不能召回该项目记忆。
3. Task02 只交付桌面端纵向闭环，不做手机端、全局记忆治理、自动摘要和完整管理 UI。
4. 刷新或服务重启后，项目、会话、消息和已写入的项目记忆仍可恢复。
5. 处理过程展示真实阶段摘要，不展示或保存隐藏思维链。

## 必须澄清的需求项

### R1 产品使用步骤仍是占位文本

Spec 的“产品使用步骤”仍写着“待确认后补充”，但 Spec 已为 `已确认`，Task02 又要求按固定六步演示验收。请将固定演示改写为正式的桌面用户旅程：创建“记忆测试”项目 → 在项目会话 A 表达偏好 → 看到新增项目记忆 → 在同项目会话 B 提问并看到使用记录 → 未绑定会话做负例 → 刷新/重启验证恢复。每一步应映射一个可观察验收点。

### R2 模糊记忆意图的 MVP 行为不够具体

已定义 `explicit / ambiguous / none`，但尚未说明 `ambiguous` 在 Task02 如何落地。建议冻结为：

- `explicit`：写入项目记忆并发送 `memory` 事件；
- `ambiguous`：不写入记忆，发送 `memory` 事件（`status=needs_confirmation`）并在界面提示“可能是长期偏好，确认后保存”；Task02 不新增确认管理页面；
- `none`：不写入，也不发送新增记忆。

这样既能验证三类识别，又不把 Task03 的治理功能提前引入。

### R3 项目绑定动作要在演示中明确

固定演示应明确：项目创建后，A、B 均在创建/发送前绑定“记忆测试”项目；负例会话保持 `project_id=null`。若首页首条消息允许携带项目选择，应明确选择控件或请求字段的最小行为；不得让前端通过提交完整历史或客户端伪造记忆范围。

### R4 模型不可用的可见行为要固定

记忆分类模型或回答模型不可用时，必须保留用户消息和失败/未分析状态，普通聊天不得静默写入记忆；SSE 发送稳定 `error` 或 `progress` 状态，用户可看到“记忆未保存/未分析”。这属于已有边界的可观察化，不要求 Task02 实现重试管理。

## 验收映射

| 需求 | Task02 验收证据 |
|---|---|
| 惰性会话创建 | 空草稿不写库；发送首条消息后获得稳定 conversation ID/URL |
| 项目记忆写入 | A 完成后有一条 `scope=project` 记忆及来源/使用提示 |
| 项目隔离 | B 能使用；`project_id=null` 的负例不出现该记忆 |
| 历史恢复 | 刷新及重启后仍能打开会话并加载消息 |
| 两屏分页 | 首次只取最新字符预算；向上滚动用 `before` 游标获取更早完整消息 |
| 最小处理过程 | SSE 中出现真实 `progress`，结束后可读取最终步骤 |
| 三类意图 | explicit 写入、ambiguous 不写入且提示确认、none 不写入 |

## 风险与停止条件

- 如果“项目记忆是否应注入未绑定会话”或 `ambiguous` 是否自动保存发生变化，应先修订 Spec 并重新确认；本报告不授权扩大范围。
- 如果实现只能通过复用论文知识库/论文任务数据库保存记忆，应停止并退回技术评审；Spec 已明确要求独立存储。
- 如果流式中断无法保留已生成部分或会把旧会话 token 写入新会话，不得进入固定演示验收。
