# 模型库（Model Registry）

> 本文件是项目唯一的模型来源。spec 中"执行配置"段的模型必须从此处选取，不要在 spec 或代码里硬编码模型名。
> 选型原则：**能力够用 + 价格最低**；中低复杂度角色（初级开发、测试）优先用本地 Ollama 模型以省成本，架构师/开发主管等强推理角色用线上旗舰模型。
> **本地模型名必须以 `ollama list` 实测，禁止凭空猜测**：填写 spec 执行配置或维护本文件前，先运行 `ollama list` 取本机真实已装模型；未核实的本地模型名一律无效。本机无 Ollama 时相关角色回退线上模型并备注原因。架构师角色由当前执行任务的 Agent 自身承担，"架构师"模型填该 Agent 实际使用的模型。

## 选型速查

- 架构师 / 开发主管 → 线上旗舰（Opus / GPT-5.1 / Gemini 2.5 Pro）；本机有 Ollama 时开发主管可优先本地 `qwen3.8:27b`。
- 初级开发 / 测试 → **优先专门的 coder 模型**：`qwen2.5-coder:14b`（约 10GB，首选）或 `deepseek-coder-v2:16b`（约 11GB，拉取中）；本机已实测可跑时也可用 `oamazonasgabriel/qwen3.8-27b:q4-km-32gbGPU`（量化 27B）兜底；显存极紧时退回 `qwen3.5:9b`；本机无 Ollama 时回退线上 `*-mini` / `*-flash`。
- 产品经理 → 本地 `qwen3.5:9b` 即可胜任产品使用步骤写作。
