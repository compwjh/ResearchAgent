1. **三个 spec 的收口都没有独立评审**：011 技术评审与验收报告由架构师代行（`tech-lead` 分派 aborted 未重试、`tester` 未分派）；

2. **011 需求评审是事后补做**：不能替代实现前拦截，边界表述偏差当时只能事后改 spec 追认。
   本轮签字只解除「签字栏为空」，**不追认评审独立性**。
3. **036 文档与证据脱节**：台账 `:397` 早在 2026-09-13 已记「已完成」，spec 却仍写「已确认」，
   还引用了不存在的 `036-tech-review.md`、把已通过的验收写成「待评审（未执行）」。
4. **039 编号撞号**：`039-*-review.md` 三份全属于另一个 spec（`039-api-e2e-manual-acceptance-protocol`）
   且验收结论为 BLOCKED；台账若不写全名，会把打回结论嫁接到已完成 spec 上。
5. **039 T4 未完成**：按 `architect` 裁决显式外置，不宣称全部 DoD 达成。
