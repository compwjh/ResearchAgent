## 边界（每条之后会变成一条测试）

- B1：`source="dblp"` 且无 dblp 会议 → **返回可读错误**，不得返回其它会议的结果。
- B1：`source="all"` → 结果必须包含 USENIX，不得只返回 `conferences[0]`。
- B2：单次响应含 2 个 `tool_calls` → 消息历史只追加 **1 条** assistant 消息，且每个 `tool_call` 有对应 `role="tool"` 消息、`id` 配对。
- B3：全部 Tool 禁用后点名 Skill → 有明确提示，不静默走普通链路。
- F1：连续快速点击详情 → 不出现旧响应覆盖新内容。
- F2：断网/`fetch` 抛错 → 中文可读提示，不出现 `Failed to fetch` 原文。
- F3：详情请求失败 → 三个字段统一为失败态。
