## 执行配置（由架构师填写，落盘可查）

> 模型必须从 `docs/sdd/MODEL_REGISTRY.md` 的模型库中选取；中低复杂度角色优先本地 Ollama 模型以省成本。
> **五行必须齐全**：某角色不参与就写「不适用（原因）」，**不要整行删除**（否则事后无法判断是"漏了"还是"有意跳过"）。
